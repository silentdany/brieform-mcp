# Changelog

All notable changes to the Brieform MCP server are documented here.
Registries reward active maintenance, so keep this updated with each release.

## [1.0.0] - 2026-06-19

### Added
- Public docs repository for the Brieform MCP server.
- 12 MCP tools covering the full form lifecycle: `create_form`, `update_form`,
  `publish_form`, `unpublish_form`, `get_form`, `list_forms`, `duplicate_form`,
  `delete_form`, `set_form_theme`, `get_responses`, `get_form_analytics`,
  `get_form_share_assets`.
- Streamable HTTP transport with OAuth at `https://brieform.app/api/mcp/mcp`.
- Listed on the official MCP registry, Smithery, and Glama.
